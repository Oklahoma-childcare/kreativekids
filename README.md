# Kreative Kidz Learning Academy — Website Project

A five-page responsive static website created for the Tupelo location (K830058256). The source is already deployable as a static website. It also supports Vite for local development.

## Pages
- Home (`index.html`)
- Our center (`about/index.html`)
- Age groups (`programs/index.html`)
- FAQs (`faq/index.html`)
- Contact (`contact/index.html`)

## Launch
From the project folder, run `npm install` and `npm run dev`. For Vercel, connect this folder as the root, choose the `Vite` preset, use `npm run build`, and set Output Directory to `dist`. `vite.config.js` is configured to build all five pages.

## Important
- The provided logo is at `assets/kreative-kidz-logo.png`.
- Content and page layouts are static HTML, edited directly in each HTML file. Theme colors and responsive layout are in `styles.css`. Mobile menu behavior is in `app.js`.
- Images are third-party illustrative photographs, **not actual photos of the center**. Replace them with authorized center images when available.
